# Welcome

This vault is set up for Isometria's notes on GitHub. Three steps, once:

1. **Sign in.** In the **GitHub vaults** panel on the right, press **Sign in**. A GitHub page opens with a code already copied: paste it, press **Continue**, then **Authorize**.
2. **Pull.** In the same panel, press **Pull** next to the vault you want (for example *CustomerLibrary*). The first time takes a few minutes; you can keep working meanwhile.
3. **Open it.** Each vault is a folder on the left. For calls: [[CustomerLibrary/Customer library|Calls home]].

After that: when you changed something, press **Sync** in the panel. It also brings in what others changed.

Can't see the panel? Click the GitHub icon in the left bar.

> [!note] Good to know
> - A note edited by you and by someone else at the same time gets both versions marked with `<<<<<<<` and `>>>>>>>`. Keep what's right, delete the markers, press **Sync**.
> - Don't rename the vault folders: that's how Sync knows which GitHub repo they belong to.
> - Keep this vault out of iCloud or Dropbox: GitHub already syncs it.
